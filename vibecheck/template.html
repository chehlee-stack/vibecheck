    Plan a change

    Describe the edit. Get likely entry points, affected files and a handoff brief for Claude or Codex.

    Try:

    Findings

    Review detected issues with their source evidence. Severity is a heuristic; verify the context before changing code.

    File risk

    Review priority by file. High impact calls for explicit scope, tests and human review.

    Dependency map

    Explore file connections. Select a file to inspect the evidence; filter by connection type.

    Drawing the graph…

    History

    The score at every commit, each scanned as it was. Red rings mark commits with a high-severity finding; the analyzer does not run or build those commits.

    Backtest

    Does the blast radius predict what really changes? Each commit is replayed from its parent with only older history, and the prediction is scored against the files the commit actually touched.

    What is measured, how the score is built, and what this cannot see.
